# 🚇 노선 잇기 퍼즐 (Metro Lines)

미니 메트로 스타일의 노선 연결 퍼즐 게임입니다. 역을 드래그로 연결해 노선을 만들고,
열차가 승객을 목적지까지 배달하면 점수를 얻습니다.

## 플레이 방법

1. **노선 만들기**: 역에서 손가락(또는 마우스)으로 드래그해 다른 역에 놓으면 노선이 생깁니다. 노선은 최대 3개, 색상으로 구분됩니다.
2. **승객 배달**: 열차가 노선을 자동 왕복 운행합니다. 역에 있는 승객(●▲■)은 같은 모양의 역이 목적지이며, 열차가 그 역에 도착하면 배달 완료 → +1점.
3. **게임 오버**: 한 역에 대기 승객이 6명 쌓이면 종료. 시간이 지날수록 승객이 빨리 몰려오고, 새 역도 계속 생깁니다.
4. **노선 편집**: 역을 길게 누르면 해당 노선에서 해제됩니다. 상단 칩을 눌러 노선을 선택하고 🗑 버튼으로 통째로 삭제할 수 있습니다.

## 조작

- 드래그: 역 연결 (모바일 터치 / PC 마우스)
- 탭: 해당 역이 속한 노선 선택
- 길게 누르기: 역을 노선에서 해제
- `Space`: 일시정지, `R`: 재시작
- 최고기록은 브라우저에 자동 저장됩니다.
